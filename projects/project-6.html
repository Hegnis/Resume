Video Card

10 MHz I/O-port/VGA video-card using 256EEPROM-based storage and image output

Overview

So Instead of using a Instead of using a GPU, microcontroller or FPGA, the project demonstrates how fundamental graphics hardware can be implemented using counters, logic gates and memory.

Technical Approach

the circuit is a 10 MHz crystal oscillator, which provides the clock signal for the entire system. Six 74LS161 synchronous 4-bit counters keep track of the horizontal and vertical positions on the display, while NAND gates and inverters decode their outputs to generate the synchronisation signals required by a VGA monitor.
Essentially, these counters tell the circuit where it is on the screen at any given moment. The surrounding logic takes care of deciding when a line ends, when the next one begins, and when the monitor should actually display pixel information. All of this is handled through discrete digital logic, without needing a dedicated graphics processor.
The more interesting part is how the actual image gets onto the screen. I use a 28C256 EEPROM to store pixel data, with the counter outputs determining which memory address to read. The resulting six-bit output represents RGB values, with two bits allocated to each colour channel.
A resistor-based digital-to-analogue converter then translates these values into voltage levels that the VGA monitor can interpret. This gives the card 64 possible colours and an image resolution of approximately 100 × 75 pixels.
