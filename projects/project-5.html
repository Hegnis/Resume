ML Radiology_Liver-Segmentation

A Liver Segmentation Project that generates the report after the analysis has been completed

Overview

This Project also grew from a Course, LiverSeg is a local research application for liver and hepatic candidate segmentation on CT. It is still in the works, but it includes includes a browser workspace, a FastAPI service, a two-stage ONNX Runtime inference adapter, per-component measurements, PDF and markdown reports, and a AI chat assistant to discuss the report with. This project was inspired by another GitHub Project.
